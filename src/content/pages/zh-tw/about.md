我是 Kimmy，在國立成功大學資訊工程學系。

我的興趣落在**軟硬體交界的那一層**：一個演算法在紙上跑得動，不代表它在矽晶片上跑得快。畢業專題就是在處理這件事——我們把 SLH-DSA 這個後量子簽章演算法拆開，找出 Keccak / SHAKE256 這段熱點，然後在 RISC-V 核心上長出一組專屬的指令去吃掉它。

我在團隊裡負責 FPGA 整合、bitstream 燒錄與硬體實測。這是一個「模擬跑得過、上板就爆炸」發生率極高的位置，所以我大部分的時間都花在讀波形、對時序、以及說服自己 testbench 沒有騙我。

## 我在意什麼

- **要能量測**。加速比要有數字，數字要說得出量測條件。
- **要能重現**。專案交出去以後，別人照著 README 應該要能燒得起來。
- **寫下來**。踩過的坑如果沒寫，半年後會再踩一次——這個網站的「筆記」就是為此存在。

## 硬體以外

修課上我刻意繞出資工系的範圍，選過國際金融市場與國際安全相關的課；準備研究所推甄時，這些跨領域的修課反而成了申請文件裡最能講的東西之一。

其他時候：系桌球隊、單車節系代表、在棒球場賣過票（所以我看 MLB 的時候會不自覺去看動線）。英文家教做了一段時間，TOEIC 915；日文學了快一年。
